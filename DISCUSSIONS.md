# n8n Lead Workflow Templates — FAQ / Discussions seed

Seed questions for the Discussions tab (enable Discussions in repo Settings -> Features, then copy each Q&A into a new Q&A discussion).

### Do I need to pay for n8n?
No, n8n can be self-hosted for free. Check n8n's current license terms for your use case.

### The import worked but a node shows a warning.
Re-select the node's credential or operation; node versions change between n8n releases.

### Which environment variables are needed?
`OWNER_EMAIL`, `FROM_EMAIL`, `CHAT_WEBHOOK_URL` (only for the workflows that use them). See SETUP.md.

### What is free and what is paid?
Workflows 01 and 05 are free here. The $29 pack adds a consent-first review request, a daily site check, a stale-lead digest, and a ZIP.

### Is the review request spammy?
The paid-pack version only emails customers flagged as having consented and includes an opt-out line. You are responsible for following CAN-SPAM/TCPA; this is not legal advice.

### Does this send my data anywhere?
Only to services you configure yourself (your SMTP server, your Google Sheet, your chat webhook). I receive nothing.

### Can I use it for my clients' businesses?
Yes, the MIT license allows commercial use. Keep the license notice.
